## 2026-07-05 (Generation-quality upgrade — scoring config, consent gate, hallucination grounding, banded odds)

### Changed
- **Scoring LLM config**: `/api/analyze`, `/api/essay`, `/api/essay/why-us` now call `routeLlmCall` with `temperature: 0.2` and `maxTokens: 4096` (was router defaults 0.7/2048). Low temp stabilizes rubric scores across runs; 4096 tokens prevents mid-JSON truncation on multi-school reports. `lib/llm-router.ts` now passes `temperature` through to the Anthropic Tier-3 path (previously ignored).
- **Admission odds honesty**: server clamps each `admissionOdds[].percent` into the pre-computed calibrated band from `lib/admit-rates.ts` and attaches `band` + `bandRange`. `app/analyze/page.tsx` renders the server band label with a "Calibrated range: X–Y%. Estimates, never guarantees." tooltip instead of implying single-integer precision.

### Added
- **Training-data consent gate (privacy)**: new `User.trainingConsent` / `trainingConsentAt` fields (prisma — requires `prisma db push` on deploy). `lib/training-data-logger.ts` now fails closed: examples are dropped unless attributable to a user with explicit opt-in, and emails/phones/SSNs are redacted before storage. New `/api/account/training-consent` (GET/POST) + opt-in toggle in Settings → Data & Privacy. `routeLlmCall` accepts `userId` for attribution; analyze/essay/why-us pass it.
- **Hallucination grounding for school programs**: new `lib/verified-programs.ts` whitelist (conservative, officially documented programs only). The analyze prompt now injects each target school's verified list ("cite ONLY these") or an explicit "no list on file — do not name programs" instruction, and the server post-checks `schoolMicroStrategies.departmentReference`/`essayAngle`, appending a "confirm on the official site" note + `_programVerified` flag for anything unverified.
- **Golden test suite**: `tests/golden/analyze-quality.test.ts` — 18 tests covering band calibration anchors (weak profile never "Very Likely" at Harvard; elite profiles still face lottery dynamics), anti-inflation validation, rigor/voice heuristic golden anchors, program-grounding behavior, and the consent-gate fail-closed path.

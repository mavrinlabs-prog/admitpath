## SEO — Ahrefs/SEMrush 100/100

### Findings + fixes

| # | Finding | File | Fix |
|---|---------|------|-----|
| 1 | Static `public/robots.txt` could conflict with dynamic `app/robots.ts` | `public/robots.txt` | **Deleted.** `app/robots.ts` already generates correct dynamic rules + sitemap URL from `NEXT_PUBLIC_APP_URL`. |
| 2 | Root JSON-LD used generic `Organization` schema | `app/layout.tsx:130` | Changed to `EducationalOrganization` with `educationalLevel: ["HighSchool", "Undergraduate"]` + `EducationalAudience` audience block. Ahrefs-recommended for EdTech. |
| 3 | Manifest missing `scope`, `lang`, `dir` | `app/manifest.ts` | Added `scope: "/"` + `lang: "en-US"` + `dir: "ltr"`. PWA install + lighthouse compliant. |
| 4 | Blog index title 63 chars (over 50–60 ideal) | `app/blog/page.tsx:11` | Shortened to "AdmitPath Blog — College Admissions Strategy & Stats" (51 chars). |
| 5 | Compare page description 128 chars (under 140–160 ideal) | `app/compare/page.tsx:6` | Expanded to 159 chars covering acceptance rates, SAT 25/75, GPA, enrollment, test policies, free + no sign-up. |
| 6 | API routes had no `X-Robots-Tag` HTTP header | `middleware.ts` | Added `X-Robots-Tag: noindex, nofollow` for all `/api/*` paths and protected app routes. Belt-and-suspenders alongside per-page meta. |

### Findings that were false positives (already correct)

| # | Finding from agent | Reality |
|---|---------------------|---------|
| 1 | "Add `robots: { index: false }` metadata to /analyze, /billing, /chat, /colleges, /essays" | All five layouts already have `robots: { index: false, follow: false }` declared. Agent checked client `page.tsx` files; correct location is `layout.tsx`. |
| 2 | "Pricing page missing metadata" | `app/pricing/layout.tsx` ships full metadata + `Product` JSON-LD with 3 offers (Free, Plus, Pro) + `FAQPage` JSON-LD with 7 questions. Best-in-class. |
| 3 | "CollegeLogo missing alt text" | `components/college-logo.tsx:59,75` already passes `alt={`${name} logo`}` + `loading="lazy"` on every `<img>` swap. Monogram fallback is text-based. |
| 4 | "Sitemap missing blog posts" | `app/sitemap.ts` enumerates `ARTICLES.map(...)` — 13 blog entries currently in `data/articles.ts`, all included. The "56 blog posts" referenced in earlier docs was aspirational, not the live count. |
